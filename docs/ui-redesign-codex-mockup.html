四、动画规范 Motion（v1 全量保留 + 补齐）

三档时长 150 / 250 / 400ms + 两条曲线（--ease-out 减速、--ease-std 标准）；最短 150ms——低于此值人眼感知不到"动画"，只感知"卡顿"（v3 调整：90ms 档废除）。出/退场成对：退场取同档更短值（150ms）+ ease-in。

场景动画补齐说明
复选框勾选bg/border · 150msv2 补：自绘勾选框带过渡，不再瞬变
行选中 / 悬停background · 150msv2 补：列表行统一 150ms（含 Log 虚拟行）
页切换 / 横幅 / 面板 pop / 侧栏折叠 / Toast250ms（侧栏折叠 400ms）v3 调整：时长整体上移至可感知区间

五、实施映射 Rollout v2

① 主题层：dark/light 两包 token 按本稿更新（token 名不变，只换值；Panel2/Link 沿用）；
② styles.css：面层 token 替换 + panes 卡片骨架 + 自绘 ck/sel/滚动条 + tabular-nums + CJK 字体栈 + 动效补齐；
③ 页面组件：Log 行布局重排（sha 淡化、meta 贴近）、变更页 panes 卡片容器、提交盒浮起卡片、设置/分支限宽——只动结构与样式，不动数据流；
④ 图标：横幅 emoji → 字形徽章（圆形底 + mono 符号）；
⑤ 验收：boot 断言不变 + 冒烟全绿 + GITTER_SHOT 钩子深浅主题截图对比 v1。

评审意见直接回复：面层亮度、卡片化边界、Log 行布局、控件样式——逐项可调。确认后按 §五 实施。
