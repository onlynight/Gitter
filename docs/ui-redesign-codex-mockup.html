一、设计原则 Principles

① 单色优先：色彩只留给「含义」——git 状态（绿/红）、警告（琥珀）、其余一律灰阶；主按钮用反白而非品牌色。
② 字号上调一档：正文 12.5 → 13px，列表 12px，区块标签 11px 大写加字距；行高 1.55——信息密度略降、可读性换台阶。
③ 4px 间距栅格：面板内边距 12–16px，列表行高 30–32px（现 26–28px），工具栏 40px——呼吸感来自间距而非空行。
④ 圆角分级：控件 5px / 卡片 8–10px / 徽章全圆；边框一律 1px 低对比，浮起靠背景色阶而非阴影。
⑤ 动效克制：只做「状态反馈」不做「装饰动画」，全部 ≤240ms、减速曲线，尊重系统减弱动态设置。

四、动画规范 Motion

三档时长 + 两条曲线，全部 CSS 变量（--dur-fast/base/slow、--ease-out/std）； 只做状态反馈，不做装饰动画；系统开启「减弱动态效果」时全部时长归零。

时长值曲线用于
--dur-fast90ms--ease-std (.2,0,0,1)悬停背景、按钮按压（scale .98）、焦点环、行选中
--dur-base160ms--ease-out (.16,1,.3,1)命令面板/菜单/弹窗 pop、横幅滑入、tooltip、页切换淡入
--dur-slow240ms--ease-std侧栏折叠（宽度）、SplitPane 拖动释放回弹、面板展开
场景动画说明
页切换（keep-alive 显示）fade + translateY(4px→0) · 160ms只对「显示的那个页面」播入场；隐藏不播出场——切换保持瞬时感
横幅（错误/安全网发现）slide-down + fade · 160mstranslateY(-4px→0)；关闭反向 120ms ease-in
命令面板 / 右键菜单 / Modalscale(.985→1) + fade · 160mstransform-origin 顶部居中；遮罩 fade 单独 120ms
侧栏折叠/展开width · 240ms文字标签同步淡出（80ms）；折叠中禁用 hover 过渡防抖动
列表行 / 导航项悬停background · 90ms无位移；选中态与悬停同曲线
按钮按压scale(.98) · 90ms抬起即回弹，无 keyframes
复选框勾选check 短画 · 120msaccent-color + 简单 scale 闪现，不做描边动画
Toast 通知slide-up + fade · 160ms出场 120ms ease-in；多条 stack 间距 8px
终端/日志滚动无动画性能红线区域，任何滚动不加 transition

五、实施映射（评审通过后执行） Rollout

① 主题层：gitui.theme.dark/light 换 token 值（上表色板）+ 新增 c-Panel2 / c-Link 两个 token（theme-framework 格式向后兼容）；
② styles.css：字号阶梯/间距/圆角/组件样式重写（按钮三态、分组标签、横幅卡片化、行高 30px），零字面色原则不变；
③ 动效 tokens：--dur-*/--ease-* 进 :root，组件挂 transition；prefers-reduced-motion 全局归零；
④ 页面组件微调：分组标签大写化、提交盒重排、diff 行距 1.7；不动任何逻辑与数据流；
⑤ 验收：boot 断言不变 + 冒烟全绿 + 浅/深主题各过一遍 + reduce-motion 开关对比。

评审意见直接标在本页或回复文字均可：色板明暗、字号档位、行高密度、圆角大小、动效时长——任何一项可单独调。
