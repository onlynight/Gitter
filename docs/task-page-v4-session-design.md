## 一、秩序三来源（本稿的排版公理）

| 公理 | 规则 | 违背即乱 |
|---|---|---|
| **密排节奏** | 同一串动作之间 **gap=0**（行距=行高，连续 ⏺ 行贴排）；事件与事件之间 18px；盒子（气泡/授权/todo）前后 14px。截断提示 `… +N 行` 并入结果尾行之后，**零间隙、同字号、弱灰**，不单独成段 | 均匀间隙 = 没有分组 |
| **单一左轨** | 全部块（动作行/正文/思考/meta/回合行/日志行）共享同一条 **28px 图标轨道（16px 图标在动作行高度内垂直居中）**，内容一律从 x=28 起；结果展开为**与左轨对齐的圆角读出框**；子代理嵌套再进一档。图标靠密排自身连成轨 | 多种左边缘 = 各种缩进 |
| **克制用色** | 默认全灰三阶（text/dim/dim2）；**红=错误**（肘弯+Error 首行+失败摘要）；**琥珀=运行中**（图标闪烁、流式 ✻）**与等待授权徽标**。其余一律去色：M/A/D、+N −M、todo 进度条、用户气泡、**授权浮层**全部灰色。diff 着色**贴文字**（width:max-content），不做通栏色条 | 颜色标记类别 = 噪声 |
| **默认单行** | 每个操作默认只有一行；结果与 ⎿ 整体隐藏，点击动作行在 **单行↔全文** 间切换（展开即 ZCode 读出样式，无中间截断态）。运行中例外：实时 tail、结束自动收起。详细模式（ctrl+o）一键覆盖折叠默认 | 默认摊开输出 = 淹没重点 |
| **操作图标** | 每类操作一枚 **18px 线性图标（大于文字，描边 2.25 防半像素模糊）**置于左轨，与文字间距≈6px（映射沿用 `taskIcons.tsx toolIconName`：读=文件、搜索=放大镜、终端=提示符、编辑=铅笔、写入=文件+、子代理=机器人、变更组=diff）；默认 dim 灰单色，**进行中=图标琥珀闪烁**，错误=图标红。**思考不斜体**，仅低饱和度字（dim2） | 图标上彩色 / 斜体 = 噪声 |

**符号收敛**：文本符号只允许 4 个——`✻`（思考）· `·`（元信息前缀）· `▸`（可折叠行）· `❯`（授权浮层选中项）；动作行的类型语义交给工具图标，不再用符号表达；结果展开由**圆角读出框**承载（肘弯折线移除）；**助手正文不加段首标记**，直接 markdown 文本流。M/A/D 状态字母保留但去色（mono dim2）。

## 四、交互清单（本轮新增加粗）

- **所有操作默认单行折叠**（结果整体隐藏）；点击动作行在 单行↔全文 间切换；展开为圆角读出框，max-height+opacity 动画，340px 内滚动；手动操作不受全局态锁死
- **详细模式**（照抄 ctrl+o，快捷键落地时按冲突裁定）：一键覆盖折叠默认——全部结果展开、思考展开、日志逐条
- **用户气泡 hover：复制（全部）/ 编辑（仅最新未完成一条）**；编辑态 = 原位 textarea + 取消/重新发送；重发中断当前请求并以新文本重启，气泡留「已编辑」标
- **agent 最终回复 hover 右上「复制」**；结果展开态 hover「复制」
- **授权/提问浮层**（覆盖 composer）：点击选项 / ↑↓ 选择 / Enter 确认 / Esc=拒绝 / 数字键直选；输入框可切**自定义答复**（Enter 发送）；批准后浮层消失、composer 恢复，对应动作行由琥珀「等待授权」转运行态（图标闪烁 + tail）
- **composer 既有功能全量保留**：模式循环 / 模型 / @ 文件补全 / / 命令菜单 / 图片粘贴附件 / 上下文余量条 / 排队消息行；@ 与 / 浮层悬于输入框上方，Esc 或点击外部关闭
- 回合/日志 ▸ 点击折叠展开；子代理点击展开嵌套
- 状态行随运行态常驻底部，Esc 中断

## 七、验收清单

1. 默认状态下**每个操作只有一行**——10 个动作的回合 ≈ 10 行，扫图标行即可复述 agent 干了什么；
2. 全屏只有一条左轨边缘；没有右缘数字列；结果展开是圆角读出框（有动画、340px 内滚动）；
3. 除错误红、运行/等待授权琥珀外全屏无彩色；diff 色不宽于文字；授权浮层黑白；
4. 错误步骤不展开也能定位（图标红 + 行内红色 `失败 · exit N`）；
5. 一屏文本符号 ≤4 种、每类操作一枚图标；流内盒子只有用户气泡、todo、结果读出框三种——待决策一律走 composer 浮层；
6. 任意用户消息可复制；最新未完成一条可编辑重发；agent 最终回复一键复制；
7. 详细模式一键全展开，再按恢复折叠默认；
8. composer 保留既有功能全量：模式循环、模型选择、@ 补全、/ 菜单、图片附件、上下文余量、排队显示；
9. 回合结束后执行过程自动折叠为一行摘要，屏上常驻的只有 用户消息、agent 结论（顶格）与进行中的回合。
