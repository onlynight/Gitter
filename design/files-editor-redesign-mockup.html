一 · 现状问题（本稿逐一替换）
  • 树：每行一条 border-bottom 成网格；emoji 图标（📄/▶/▼）；git 状态用 Material 硬编码色（#FFD700/#4CAF50/#F44336/#2196F3），活动行用 Material 蓝 rgba(33,150,243,.2)，与近单色壳层冲突；agent 回合=紫色加粗最扎眼。
  • 标签：活动标签背景取 var(--c-bg) —— 该 token 不存在，实际等于透明，活动标签与普通标签无任何视觉区分；脏点用 #FFD700；关闭钮常显且挤在文字旁。
  • 空态：📁📝 emoji 居中，无动作入口。
  • 树头：Select 下拉 + 输入框竖向堆叠占两行 chrome；分栏宽度按百分比（20%–70%），窗口缩放时树宽漂移。
  • 编辑器：Monaco 背景硬编码 #1e1e1e，与主题 --c-base #0D0D0D 脱节；无面包屑、无光标位置/语言/EOL 状态显示。
二 · 视觉规范（全部走主题 token，零字面色进入组件）
  • 层级：侧树/标签条/编辑区同为 --c-base（结构线 --c-border 划界）；活动标签 = --c-panel2 浮起卡片 + --c-border-strong 描边环；菜单/浮层/对话框 --c-panel2 + 描边承担层级，页脚 --c-panel。
  • 树行：24px 定高、无行线；缩进参考线 1px --c-border（对齐祖先 chevron 列中心）；hover=--c-hover；活动=--c-selected；键盘焦点=1px --c-link 内描边。chevron 16px、120ms 旋转过渡。
  • git 状态映射（名字着色 + 行尾字母徽标，删除加删除线）：

  • 标签（家内规范，终端页 term-tab 同款形制）：26px 圆角 chip 底对齐（间距 4px、圆角 6），无通栏矩形、无强调色顶线；活动 = --c-panel2 底 + --c-border-strong 描边环凸出，hover = --c-hover；文件名随 git 状态着色（悬停与活动态回收为正文色避免花）；预览标签斜体；脏 = --c-text2 圆点，与关闭钮互斥显示（hover/活动显 ×，其余显 ●，即终端页「× 仅 hover 显现、激活常显」规则 + 脏态扩展）。
  • 文件图标：16px 单形文档 SVG 按扩展名着色（ts 蓝/js 黄/json 黄/css 蓝/html 橙/md 蓝/svg 紫），目录保持中性 --c-text3 描边。v1 内置「扩展名→颜色」映射表即可，P3 可升级 Seti 风格全量 SVG 集。
  • Monaco 主题修正：editor.background 跟 --c-base（替换硬编码 #1e1e1e），行高亮 --c-text 4% 叠加，选区 --c-link 30% 叠加，行号/光标/空白符取 Text3/Text/Text3；语法色继续由宿主 syntax 表注入（filesMonaco.ts buildTheme 机制不变，本稿代码配色为 GitHub Dim/Light 系草案）。
三 · 交互规范（VSCode 范式逐一落地）
  • 标签三态：单击文件=预览标签（斜体，唯一，再开其它文件即替换）；双击/再次点击/编辑后=转正；中键或 × 关闭。关闭含未保存更改的标签 → 三选一对话框（保存/不保存/取消）。
  • 树过滤：树头漏斗钮展开筛选行（或直接键入）；按名筛选实时过滤 + 命中子串高亮（amber 32% 叠加）+ 右侧计数；Esc 清空并收起；过滤态强制全展开并合成祖先目录（沿用现有实现语义）。
  • 模式 tabs 迁入树头：变更(N) / 回合(N) / 全部 与「文件」标题同行（30px 一行 chrome 替代现状两行堆叠）；变更/回合显示计数徽标；默认落在「变更」。
  • 树头动作钮：筛选/刷新/全部折叠，hover 或 focus-within 显（筛选激活时常显）；与列表/详细信息设计稿同一显隐策略。
  • 定位与揭示：激活标签时自动在树中揭示该文件（展开祖先、滚动到位、1s 闪光）；面包屑每段可点击同样定位；右键菜单提供 打开 / 查看变更 / 复制路径 / 复制相对路径 / 在外部编辑器中打开 / 在资源管理器中显示。
  • 分栏：改为定宽像素（默认 278，范围 170–520，双击复位），持久化 px 而非比例；Ctrl+B 整体收起/展开树。
  • 保存反馈：自动保存照旧（300ms 防抖，可在设置关）；显式 Ctrl+S 后页脚左侧闪「✓ 已保存」，标签条右侧「保存中…」仅在有延迟时出现；mtime 冲突对话框见 ③。
  • 键盘：Ctrl+P 快速打开（模糊子序列匹配，↑↓ 选择、Enter 打开、Esc 关闭）；Ctrl+Tab 循环标签；Ctrl+W 关闭；Ctrl+S 保存；Alt+F 筛选；树内 ↑↓ 移动焦点、Enter 打开、←→ 折叠/展开。浏览器原型可能拦截 Ctrl+Tab/P，应用内（Electron）无此问题。
  • 标签溢出：横向滚动 + 两端渐隐，悬停显示左右步进箭头（P2 可先仅滚动）；拖拽重排列 P3。
  • P3 备选（本稿不做）：标签分屏、Open Editors 区、树 sticky scroll 目录头、quick open 符号模式（@）、底部 DiffView 面板挂载。
