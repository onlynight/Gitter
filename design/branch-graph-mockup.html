设计要点 · 三等分栏（图 | 分支 | 标签）
  • 位置：页面三等分栏，分支图占最左 1/3 全高——竖向空间完整，泳道纵向滚动浏览全部拓扑；中栏本地分支、右栏标签。
  • 泳道：每条分支一条彩色泳道（颜色按分支稳定分配）；分叉 / 合并用曲线衔接；当前分支固定最左主泳道。
  • 节点：提交 = 圆点；分支 tip = 圆点 + 分支徽章；tag = 紫徽章；HEAD = 描边徽章。
  • 窄列适配：提交行只显示 sha + 徽章 + 主题（截断），作者/时间移入悬停 tooltip；徽章超宽自动截断。
  • 关系数字：分支行新增 ↑n 领先 / ↓n 落后徽章（相对 upstream，无则相对当前分支）。
  • 交互：行悬停高亮、点击选中；图与列表联动（徽章悬停同步高亮对应分支行）。
  • 数据/实现：新增 RPC branch.graph——git log --all --graph --date-order 解析泳道结构（cap 300 + 加载更多），前端虚拟化 + SVG 泳道；后端零新依赖。
