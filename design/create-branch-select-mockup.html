设计要点
  • type tab 在弹层内部（搜索框下方）：分支 / 标签两类，不占对话框空间；打开弹层时 tab 自动定位到当前选中值的类型。
  • 分支 tab 内保留 本地 / 远程 分组；「当前 HEAD」钉在分支 tab 顶部，不参与搜索过滤（默认项永远可见可选）。
  • 搜索 = 关键字包含：大小写不敏感的子串匹配（name.includes(kw)），非全量/前缀匹配；命中片段高亮；只过滤当前 tab；tab 上实时显示各自命中数；无命中给空态提示。
  • 键盘：打开即聚焦搜索框；↑↓ 在可见项间移动、Enter 选中、Esc 关闭；tab 用鼠标点击切换。
  • 触发钮带类型徽标（HEAD / 分支 / 标签），选中 tag 后仍以徽标区分，不再依赖 “(tag)” 文字后缀。
  • 实现落点：扩展现有 kit/Select（新增可选 props：tabs / searchable / group），不新建组件；后端零改动（branches.state 已含全部数据，过滤纯前端）。
