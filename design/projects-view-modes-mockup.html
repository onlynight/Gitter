设计稿 · 项目页 — 查看方式：卡片 / 平铺 / 列表 / 详细信息（可交互原型，仿 Windows 资源管理器视图）
卡片
设计要点
  • 四种查看方式（信息密度递增，数据同源 projects.list，纯视图映射）：卡片=现状默认不动（有边框卡、路径可换行、操作常显）；平铺=卡片质感双行（panel 底 + 描边，图标 18px + 名称/chip + 路径单行截断），悬停浮起，一格更窄更密；列表=单列一行 32px（名称定宽 180px + 路径同行延伸截断）；详细信息=列头 + 对齐列 + 细分隔线，Windows 资源管理器形态。
  • 切换器=工具栏右端分段控件（仅图标 + tooltip），不动左侧「添加项目」；当前项 Selected 底。键盘：Tab 进入后 ←→ 切换；空项目时切换器照常显示但无意义项不隐藏（视图本身与数据无关）。
  • 操作钮可见性：卡片/平铺常显（保持现状可达性）；列表/详细信息行高紧凑，改为悬停或键盘聚焦时显现（:hover / :focus-within），腾出空间给路径列。整行点击=打开项目（与现状一致），操作钮 stopPropagation。
  • 当前项目标记：三种新视图一律保留 Projects_Current chip（蓝 chip），位置随行内布局内联。
  • 详细信息排序 = 可选增强：列头「名称/路径」点击循环 升/降/恢复默认（默认=添加顺序，即后端返回序）；排序纯前端，不回写后端。首版可不做。
  • 持久化：视图选择记 localStorage("gitter.projects.view")，仅前端、零后端改动（projects.list / DTO 均不动）。
  • i18n 新键（Strings.tsv）：Projects_View（视图）、Projects_ViewCard（卡片）、Projects_ViewTiles（平铺）、Projects_ViewList（列表）、Projects_ViewDetails（详细信息）。
  • 实现落点：仅 ProjectsPage.tsx（viewMode state + 按模式渲染分支，卡片分支保持现状）与 styles.css（新增 .tile-grid / .list / .details 三组选择器，本页组件样式即草案）；SDK/bridge/后端零改动。空态与错误横幅不随视图变化。
  • 主题：右上角按钮切亮/暗（theme.gitui.solid 实测值），四种视图两套主题下均验证对比度。
