① 三个入口并存：a) 行悬停图标（＋ 暂存 / ↩ 放弃修改；未跟踪 = 🗑 删除）——扩展现有悬停暂存钮的位置与样式；b) 右键菜单（保留，文案按文件状态二分：已跟踪「放弃修改…」/ 未跟踪「删除文件…」）；c) 多选批量：行首勾选框（悬停出现）+ Ctrl/Shift 多选，选中 ≥1 时列表顶部浮出「选择条」（已选 N · 暂存 · 放弃修改… · ✕）。三个入口最终走同一个 changes.discardFile（多选新增 paths 数组参数或循环调用）。
② 多选与打开差异不冲突：点行仍是打开差异（现状不变）；勾选只认行首 checkbox 与 Ctrl/Shift 修饰键。已暂存组不参与放弃：勾选框在已暂存组不出现（行尾灰字提示），多选范围仅「更改 / 未跟踪」组——维持上版「已暂存内容必须先取消暂存才能放弃」的防手滑决策。
③ 批量确认框：同一 Modal danger 模式（红底实心键），逐行列出文件与状态字母；按钮文案带数量「放弃 N 个文件」。混合已跟踪 + 未跟踪时按类分行：已跟踪 = 回到 HEAD；未跟踪 = 永久删除（红字），两类后果都写明。
④ 工具栏全面图标化：Fetch / Pull ▾ / Push / Stash / ＋新建分支全部 26px 图标钮 + tooltip（与 stash 设计稿同一套图标），废弃文字按钮；图标语义 ↩ = 放弃（回 HEAD）、🗑 = 删除（不可从 git 恢复），红色 = 不可逆。
⑤ 选择条消失时机：✕ 或 Esc 清空选择；执行暂存/放弃后自动清空；切换页面/刷新仓库时清空。
试玩：A 场景点行勾选/取消 → 选择条计数联动 → 「放弃修改…」看批量确认框（列出所选）→ 确认后行消失；B 场景点行呼出菜单、悬停行看 ↩ 图标；C 场景 hover-demo 行常显 🗑，点击直达删除确认。
