设计要点
  • 入口与分栏：终端标签条右端（重启钮旁）新增「文档」图标钮，点击在右侧分出 2/5 宽度（终端:文档 = 3:2）承载文档面板，再点或点面板 × 收起；开合带 250ms 宽度过渡，终端 xterm 随 fit 重排。分隔条可拖拽调宽：默认比例 0.4，拖动实时跟手（拖动中禁用过渡），钳制 0.26–0.65，松手才持久化（本稿用 localStorage 模拟，落地 = settings 新增 terminalDocFraction，复用 kit/SplitPane 的「拖动结束写 settingKey」语义）；双击分隔条恢复默认 2/5；下次打开面板/重启应用按已保存比例还原。
  • 文档内容：单份内置 Markdown「Git 命令手册」，命令标题统一「中文功能名 + 命令名」（如：配置 git config、下载远程仓库 git clone），每条命令三件套 = 用途 + 常用参数 + 调用示例，示例统一以 GitHub 仓库 gitter-demo/todo-app 为例；一、配置与初始化 / 二、日常高频命令（参数用小表格）/ 三、其余全部命令分类详解（参数行内紧凑式，含 plumbing 全量收录）/ 四、附录字母序索引（命令 → 一句话 → 所属章节）。经 kit renderMarkdown 渲染进 .md-body 容器。
  • 汉堡目录浮层：面板左上 ☰ 打开面板内左侧滑出的浮层（264px + 25% 黑遮罩），不遮终端区；目录三级（h2 章节 / h3 分类 / h4 命令递进缩进），scroll-spy 滚动联动高亮当前章节；点击条目平滑滚动到对应锚点并收起浮层；Esc / 点击遮罩关闭（搜索框内 Esc 先清关键字）。
  • 目录搜索：浮层顶部搜索框，按目录标题子串包含匹配（大小写不敏感），命中片段高亮 + 实时命中数，无命中给空态；清空关键字恢复全量目录。
  • 正文查找：面板右上 ⌕ 展开查找条（与目录钮同排，互不遮挡）：全部命中琥珀淡高亮、当前命中实色，n/m 计数（无命中红字 0/0），▲▼ / Enter / Shift+Enter 循环定位并滚动居中；Esc 或 × 清除高亮收起。查找范围仅文档正文，不进目录浮层。
  • 实现落点：TerminalPage 增 docOpen 状态与右栏挂载；新增 GitDocPanel 组件（内置 GitCommands.md 资源 + TOC/scroll-spy/find 逻辑，可沉淀进 kit）；主进程零改动；i18n 走 Strings.tsv 新增 Terminal_Doc* 键。字形用 Segoe Fluent Icons（同应用现有 .glyph 体系）。
