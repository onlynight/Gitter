# 项目文件树

Gitter 内置的项目文件树页面，支持手动编辑代码。

## 功能

- **文件树浏览**：基于 git 仓库的文件结构，支持展开/折叠目录
- **新建文件/文件夹**：树头按钮作用于选中目录（未选中 = 根目录），右键菜单在目标目录内创建；行内输入名称，Enter 确认、Esc 取消
- **全部折叠/展开**：树头一键折叠或展开全部目录
- **Office 文档预览**：在树中点击 pdf / docx / pptx / xlsx / ods 直接在编辑区画布内预览
  （缩放、页数、外部程序打开）；标签条/面包屑/页脚布局不变，csv/tsv 仍按文本编辑
- **git 状态高亮**：M（修改）、A（新增）、D（删除）、U（冲突）、?（未跟踪）
- **Agent 回合高亮**：本回合 agent 改动的文件以紫色高亮显示
- **代码编辑**：点击文件打开编辑器，支持保存（Ctrl+S）
- **多标签编辑**：支持同时打开多个文件，标签间切换
- **搜索过滤**：按文件名搜索，按 git 状态或 agent 回合过滤

## 使用

1. 从侧边栏进入「文件」页面
2. 左侧文件树点击文件打开编辑器
3. 编辑后按 Ctrl+S 保存，或等待自动保存（300ms 防抖）
4. 右键文件可在外部编辑器打开或在文件管理器中显示

## 快捷键

- `Ctrl+S`：保存当前文件
- `Ctrl+Tab`：切换标签
- `Ctrl+W`：关闭当前标签
- 中键点击标签：关闭标签

## 注意事项

- 编辑器保存会刷新 agent 的读取记录，agent 可以继续编辑
- 文件大小限制：读取 8MB，写入 2MB
- 二进制文件无法编辑，会显示提示（Office 文档族 pdf/docx/pptx/xlsx/ods 以画布预览呈现）
